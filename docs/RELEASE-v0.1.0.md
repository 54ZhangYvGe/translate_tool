# TranEasy v0.1.0

First public release.

## Highlights

- Selection translation
- Screenshot OCR & translation
- Manual translation
- Text-to-speech
- Translation history
- Global hotkeys
- Windows DPAPI credential protection
- Installer and portable editions

## Requirements

- Windows 10/11 x64
- Your own Youdao credentials for online translation/TTS

## Known limitations

- Unsigned binaries may trigger Windows SmartScreen
- First OCR initialization may be slow
- Current UI is Chinese
- Live API calls and clean-Windows compatibility have not been fully verified

## Downloads

- TranEasy-Setup-v0.1.0.exe — recommended installer
- TranEasy-v0.1.0-win64-portable.zip — extract completely and run TranEasy.exe
